## 2. 已确认定位

> 面向微信群熟人场景的轻量商品接龙工具。系统负责商品展示、订单记录、自动统计和清单输出；不接管资金和履约。

这里使用“接龙”而非“拼团”：当前需求没有提到最低人数、最低金额或未达门槛失败，因此暂不把成团规则加入产品。

## 4. 商品发布边界

平台允许用户发布一般合法商品的接龙信息，不参与定价、收款和履约。平台不保证事前掌握每件商品，但必须提供规则、检测、举报及下架能力。

第一版负面清单至少包括：药品、医疗器械、烟草、电子烟、酒类、保健品、危险品、色情或赌博相关商品、非法票券、侵权商品，以及依法或依微信规则需要特殊资质而发布者无法证明资质的商品。

后续如开放食品、酒类等受限类目，应先补充发布者资质审核和对应服务类目，不默认开放。

| 风险              | 影响                        | 当前处理方向                                            |
| --------------- | ------------------------- | ------------------------------------------------- |

| 商品文字和图片违规       | 审核及运营风险                   | 内容安全检测、举报与处置流程                                    |

| 取消活动与接龙操作并发     | 出现活动已取消但订单仍生效等不一致         | 由服务端在同一业务事务中校验活动最终状态                              |
