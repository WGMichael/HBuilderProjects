# 小程序提审自查清单

- 文档版本：v0.1
- 文档状态：**上线前逐项核对使用**；每项结论需实际验证后勾选，不得凭印象打勾
- 适用产品版本：见 `docs/README.md` 版本总表
- 更新日期：2026-09-14
- 配套文档：`CATEGORY_VERIFICATION.md`（类目与主体核验）

> **时效声明**：本清单整理于 2026-09-14，依据的平台规则知识截止于 2026 年 5 月。微信审核口径持续变化，**本清单用于防止遗漏，不构成通过审核的保证**。提审前应对照当时最新的《微信小程序平台运营规范》复核。

## 使用方式

- 本清单在**申请到小程序 AppID 之后、正式提交审核之前**逐项执行
- 每项标注了对应的项目决策编号，便于回溯为什么要做这件事
- 标记 🔴 的是**拒审高发项**，必须优先确认
- H5 阶段无法验证的项目已单独标注，不必在 H5 阶段纠结

## 二、内容安全机制 🔴

本产品是 UGC（用户生成内容）小程序 —— 商品名称、说明、图片全部由用户填写。**微信要求 UGC 类小程序必须具备内容安全审核机制**，缺失会被拒审。

| | 检查项 | 依据 | 状态 |
|---|---|---|---|
| 2.1 | 用户发布的活动与商品**必须经过审核后才对外可见** | D-043 | ☐ |
| 2.2 | 审核机制实际生效：人工审核队列可用，或自动检测已接入 | D-057 | ☐ |
| 2.3 | 文本内容检测已接入（`msgSecCheck` 或等效服务） | D-022、D-058 | ☐ |
| 2.4 | 图片内容检测已接入（`mediaCheckAsync` 或等效服务） | D-022、D-058 | ☐ |
| 2.5 | 图片异步检测回调命中后，能够实际将商品/活动转为治理下架 | D-058 | ☐ |
| 2.6 | 活动详情提供**举报入口**，覆盖活动和单个商品 | D-022 | ☐ |
| 2.7 | 举报可被受理并形成处置结论，运营后台链路完整可用 | OPS §5 | ☐ |
| 2.8 | 具备下架能力：可下架单个商品，也可下架整个活动 | D-054 | ☐ |
| 2.9 | 负面清单已在商品发布页明确展示给团长 | D-022 | ☐ |
| 2.10 | 内容治理相关操作均写入操作日志 | D-042、OPS §13 | ☐ |

**首版负面清单至少包含**（DECISIONS §4）：药品、医疗器械、烟草、电子烟、酒类、保健品、危险品、色情或赌博相关商品、非法票券、侵权商品，以及依法或依微信规则需特殊资质而发布者无法证明资质的商品。

> **审核员会亲自发一条违规测试内容**，看你的小程序有没有拦住。服务端是否真的调用了检测接口，审核看的是功能表现而非代码。

## 八、常见拒审原因对照

| 拒审原因 | 本项目对应的防范措施 | 自查项 |
|---|---|---|
| 功能与服务类目不符 | 类目核验、提审备注说明形态 | 1.2、4.5 |

## 九、H5 阶段无法验证的项目

以下项目依赖小程序 AppID，H5 阶段不必纠结，申请到 AppID 后再补：

- 2.3、2.4、2.5（内容检测接口，需 AppID + AppSecret 换 access_token）
- 3.1（后台配置隐私指引）
- 5.1 中的 `weixin` 登录（H5 的微信登录需要公众号或开放平台 AppID，与小程序 AppID 不同）
- 4.7（小程序分享卡片）

H5 阶段用 `review_mode = 2`（人工审核）覆盖内容安全要求，登录仅用 `username`。

**待核实项**：`msgSecCheck` 新版本可能要求传入内容发布者的 `openid`。若确实要求，则通过 `username` 注册、未绑定微信的用户所发布的内容无法送检，此类内容需强制走人工审核。评审 §7 第 3 条亦将此列为未逐项核验事项，拿到 AppID 后实测确认。
