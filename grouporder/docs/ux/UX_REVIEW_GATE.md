# 群接龙 UX 需求追踪与评审门

- 文档状态：待评审
- 适用产品版本：PRD v1.1
- 流程文档：`UX_FLOW_SPEC.md`
- 状态文档：`UX_STATE_MATRIX.md`

## 1. 使用方法

本文件用于确认 UX 流程能进入低保真阶段。评审人逐项勾选并记录问题；存在事实冲突、越权、隐私泄露、无法恢复的关键异常或未标记的合规假设时，不得通过。

状态标记：

- 已确认：正式事实已明确，UX 必须遵守。
- 待架构：产品行为已明确，但实现机制需架构设计。
- 待合规：不得自行补充期限、承诺或删除策略。
- 待产品确认：当前仅为设计建议，不能作为正式业务事实或直接进入实现。
- 后续迭代：首版不实现。

## 6. 可勾选 Review 清单

### Gate A：事实一致性

- [ ] D-001～D-056 均有页面或范围映射，D-040 已明确标记被 D-043 取代。
- [ ] 不存在“一名用户同一活动只能有一张有效订单”的残留表述。
- [ ] “再下一单”与重复请求被明确区分。
- [ ] `total_stock=0` 表示不限库存，`per_user_limit=0` 表示不限购；有限上限才参与校验，每人限购按平台用户全部有效订单合计。
- [ ] 各商品已购买份数按其有效明细数量之和计算，有效总份数为各商品之和，有效订单数按订单张数单独计算。
- [ ] 收货信息为姓名、电话、完整地址及默认项；删除默认项后最早创建的剩余记录成为默认，订单保存完整快照。
- [ ] 电话未用于注册、登录、绑定、找回密码或身份核验。
- [ ] 未登录用户可浏览非敏感活动内容，提交及受保护操作会要求登录并安全回跳。
- [ ] 持有效分享入口的用户可进入活动，但敏感数据始终由服务端鉴权。

### Gate B：流程完整性

- [ ] 每条主流程均包含入口、正常路径、失败/返回路径和终态。
- [ ] 小程序双登录、注册、绑定和找回密码完整；双方已有业务数据的绑定冲突明确不提供申诉解决。
- [ ] 创建、发布审核、公开列表、参与下单、多订单、收货信息、团长管理、商品管理完整。
- [ ] 手动/自动截止、团长取消、单商品/整活动治理下架与恢复分别完整。
- [ ] 清单生成、受控下载、举报和结果查看完整。
- [ ] 运营登录、工作台、检索、统计、审核、处置、敏感访问、申诉、Excel 和审计完整。

### Gate C：状态一致性

- [ ] 页面编号在三份文档中一致。
- [ ] 活动业务状态仅为草稿、审核中、进行中、已截止、已取消，审核通过后才开放和分享。
- [ ] 活动治理状态与商品治理状态均为正常、已下架；恢复作为操作历史。
- [ ] 审核中、截止、取消、活动下架和商品下架没有被混为同一状态。
- [ ] 商品历史锁定、在售/停售与治理下架状态分开表达。
- [ ] 已取消、已作废订单不计入有效统计。

### Gate D：隐私与安全

- [ ] 参与者不能看到他人身份、电话、地址或购买明细。
- [ ] 团长只能查看本人发起活动的履约所需资料。
- [ ] 运营列表、搜索、日志和统计默认不展示完整敏感资料。
- [ ] 内容运营、超级管理员、审计查看者不能因角色本身查看完整收货资料。
- [ ] 解敏仅限账号与隐私专员，且需事项、原因、二次验证和对象范围。
- [ ] 运营后台不能预览、下载或重新生成团长 Excel。
- [ ] 下载链接每次校验权限、短期有效且过期失效；界面不暴露固定地址。
- [ ] 用户可控 Excel 文本不能成为可执行公式。

### Gate E：异常可恢复性

- [ ] 弱网、断网、加载失败和结果未知有不同反馈。
- [ ] 写操作重复请求返回原结果或最终状态，不重复生效。
- [ ] 发布审核、库存、限购、截止、取消、商品/活动下架、停售/恢复竞争均以服务端最终状态为准。
- [ ] 绑定冲突、双方已有业务数据和并发绑定均有安全返回路径。
- [ ] 权限撤销、账号停用、会话/二次验证过期后立即失效。
- [ ] 统计延迟展示统计时间/截至时间，不用零值替代未知。
- [ ] 下载链接过期和清单版本变化均可安全恢复。

### Gate F：首版范围

- [ ] 未引入支付、退款、采购、配送、物流、核销或售后。
- [ ] 未引入商品规格、成团门槛、营销、店铺或供应链。
- [ ] 未引入订阅消息或主动微信通知。
- [ ] 未引入团长代补录、活动密码或参与审核。
- [ ] 未引入团长 Web 后台、运营数据编辑或运营 Excel 获取。
- [ ] 未引入运营统计导出、定时报表、排行榜、画像或批量高风险处置。

### Gate G：数据生命周期、合规与外部阻塞

- [ ] 订单相关数据的三年期限从活动截止或取消之日起计算。
- [ ] 三年届满后删除或匿名化订单中的姓名、电话、地址及账号关联，匿名汇总不可反查个人。
- [ ] 账号、当前资料和地址簿随账号存续，账号注销时删除或匿名化。
- [ ] 存在本人审核中/进行中活动或尚未截止/取消活动中的有效订单时阻止注销，并列出需先处理的对象。
- [ ] 注销后仍在三年期内的订单只用于争议、审计和必要合规限制处理，不作为正常展示或一般统计来源。
- [ ] Excel 临时文件、举报/内容安全/审计记录及备份规则仍标记待合规/架构，未擅自套用三年或永久期限。
- [ ] P1-09 明确为当前产品判断，且仍标记为架构前置的微信主体/服务类目正式核验。
- [ ] 商品负面清单、内容检测、举报、下架和审计均有入口。
- [ ] “接龙成功不代表已付款或平台担保成交”的范围可在后续原型承载。

### Gate H：运营统计与权限

- [ ] 运营统计查看权限独立且默认关闭，不随任何角色自动获得。
