特产小店 · 微信小程序原型

轻量起步版 · 点击商品/按钮可在页面间跳转体验 · 手机尺寸预览

下方 8 个页面覆盖「逛 → 看 → 买 → 付 → 收 → 复购」完整链路。点卡片进详情，点"立即购买/去结算"走下单流程。

核心下单流程

首页/分类浏览 → 商品详情（选规格/数量）→ 加入购物车 或 立即购买 → 确认订单（选收货方式：快递配送 / 同城自提）→ 微信支付 → 支付成功 → 待发货 → 已发货（填物流单号）→ 确认收货 → 可评价 / 一键再买。

会员与复购（轻量）

微信一键登录即成为会员 → 每单累计成长值/积分 → "我的"可见历史订单，一键再买 → 商家可发优惠券/新品推送提醒回购。
