
后台主要功能点 ： 

├── 商品管理
├── 分类管理
├── 订单管理
├── 用户管理
├── 物流管理
├── 营销活动
├── 数据统计
└── 系统设置


功能点功能概述：

## **商品管理**

可以：

新增商品

编辑商品

上下架

库存

价格

分类

商品图片

---

## **订单管理**

订单列表：

```
待付款

待发货

已发货

已完成

退款
```

点击订单：

```
用户信息

收货地址

商品

金额

物流

备注
```

---

## **客户管理**

查看：

```
客户昵称

电话

购买次数

累计消费

最近购买时间
```

方便维护老客户。


## **物流管理**

发货后：

填写：

```
快递公司

快递单号
```

客户可以查看物流。

---

# **搜索**

支持：

```
搜索商品

搜索品牌

搜索关键词
```

例如：

```
枣

核桃

葡萄干

礼盒
```

---

# **客服**

建议直接：

```
微信客服

电话

一键拨打

留言
```

---

# **分享功能**

这是微信商城最重要的。

商品详情：

```
分享到微信

分享到群

生成海报

复制链接
```

很多订单都来自分享。

---

# **首页运营**

后台可以：

```
轮播图

推荐商品

热卖商品

新品

公告
```

不用改代码即可更新。
