# 数据层（data 层）架构说明

按 `ai-project/docs/Architecture.md` 的技术栈（uni-app Vue3 + TS + uniCloud）重构：**页面不再写死数据，统一通过数据层获取**。后期后台就绪，改一个开关即可无感切换到真实数据库。

## 分层结构

```
页面 (pages/*.vue)
   │  只负责展示，向数据层要数据
   ▼
store/            全局状态（购物车、用户），Vue3 reactive 单例
   │
data/             ★ 数据层：对外只暴露一个 db，内部可切换来源
   ├── datasource.ts       IDataSource 接口 = 前后端「协议」
   ├── mock-datasource.ts  本地假数据实现
   ├── cloud-datasource.ts 后台实现（调用 api/）
   ├── mock/index.ts       假数据（结构 = 后台表结构）
   └── index.ts            按 config.USE_MOCK 选择实现，导出 db
   │
api/index.ts      后台接口定义（uniCloud 云函数 / HTTP 两套）
utils/request.ts  HTTP 请求封装（uni.request → Promise）
types/index.ts    领域模型 + ApiResult 统一响应协议
config/index.ts   开关：USE_MOCK / backend / baseUrl
```

## 页面怎么用

页面只依赖 `db`，完全不知道数据来自哪里：

```ts
import { db } from '@/data'

const products = await db.getHotProducts()
const detail   = await db.getProductDetail(101)
```

购物车同理，直接用全局 store：

```ts
import { cartStore } from '@/store'
cartStore.add(product, sku, 1)   // 自动响应式 + 本地持久化
cartStore.totalPrice.value       // 选中合计
```

## 切换到真实后台（只改一处）

1. 打开 `config/index.ts`，把 `USE_MOCK` 改为 `false`。
2. 选后端类型：`backend: 'cloud'`（uniCloud 云函数）或 `'http'`（传统接口）。
3. 后台按 `types/index.ts` 的模型返回数据，遵守 `ApiResult { code, message, data }` 协议即可。

页面、store、组件**一行都不用改** —— 这就是「data 层通过协议与后台数据库同步」的意义。

## 协议约定（前后端对齐）

- 所有接口返回统一包裹 `ApiResult<T>`：`code=0` 成功，`data` 为业务数据。
- 分页统一用 `PageQuery` / `PageResult<T>`。
- 商品、订单、用户等表结构以 `types/index.ts` 为准，后台建表尽量字段对齐，减少转换。
